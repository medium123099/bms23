TreeLife Stimulation — обновлённый комплект файлов сайта.
Структура папок = структура на хостинге (css/, js/, assets/, config/).

ЧТО ИЗМЕНЕНО В ЭТОЙ ВЕРСИИ
1. На главной убрана строка «Аппараты TreeLife для профессионального
   и домашнего применения» над заголовком.
2. Стиль сайта: меньше скруглений (карточки, кнопки, поля стали более
   геометричными), более выраженные тени и лёгкие эффекты при наведении
   (карточки товаров и отзывов приподнимаются и слегка поворачиваются,
   кнопки «привстают»), тонкая зернистая текстура и цветная полоска
   сверху страницы — всё это в файле css/style.css.
3. Внизу справа на всех страницах для посетителей (кроме админки)
   добавлены плавающие кнопки WhatsApp и Telegram на номер
   +7 962 866-80-00.

КАК ЗАГРУЗИТЬ
1. Загрузите всё содержимое папки в корень сайта bms23.ru с заменой
   файлов. Файл .htaccess — скрытый: включите показ скрытых файлов
   в файловом менеджере. Если в корне уже есть свой .htaccess —
   не затирайте его, а вставьте строки из нового в начало.
2. НЕ заменяйте config/database.php на сервере — оставьте свой рабочий
   файл с реальным паролем от базы. Файл в этом архиве — только
   для примера структуры.
3. В корне config/ лежит файл .htaccess с "Require all denied" —
   он закрывает прямой доступ к папке с паролем от базы. Загрузите
   его тоже (тоже скрытый файл).
4. Удалите с сервера test.php, если он там остался, — он открыт
   всем и показывает число пользователей в базе.
5. Откройте bms23.ru/order.php — должно появиться «Неверный запрос»
   (значит файл работает). Таблицы tl_orders, tl_reviews и
   tl_callbacks создадутся автоматически при первом обращении.
6. В privacy.html впишите наименование ИП/ООО и реквизиты
   (найдите слово «наименование»).
7. Обновите страницу через Ctrl+F5, чтобы подтянулись новые
   css/js файлы без кэша браузера.
